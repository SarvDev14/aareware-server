# Credits and licences

Aare–Ware Coastal Drive is a hobby project. Almost everything in it (the coast, the villages, the temple,
the fort, Ratnagiri station, the sounds and the other traffic vehicles) is generated by code inside the
game. The one exception to "the sounds" is the Ratnagiri Rocket's engine (version 1.25.0), which is cut from the owner's own recording of a Honda CBR 650R. The items below are third-party models and pictures that were added in versions 1.7.0 to 1.25.0. Each one was
changed for the game (optimised, re-textured, recoloured), which the licences ask us to say.

## Things to settle before sharing the game publicly

- **McLaren F1 (CC BY-NC 4.0)** may be used only for non-commercial purposes. A free hobby game is fine; ads, a
  paid version or sponsorship are not. Remove `assets/mclaren.glb` and its entry in `src/assets.js` / `src/carspecs.js`
  if that could change.
- **Mixamo animations** are free to use inside a game or project under Adobe's Mixamo terms, but the clips themselves
  may not be handed on as a stand-alone animation pack. The game page contains them in packed form (`assets/anims.anm`);
  do not publish that file separately.
- **Ford F-150 (Sketchfab "Standard" licence)** is not a Creative Commons licence: it lets you use a downloaded model
  inside your own project, but not hand the model files on to others, and the game page contains the model. It is
  safest for private use with friends. For a public release, replace it or ask the author.
- **Tank wagon (Sketchfab "Standard" licence)** has the same limits as the F-150: you may use the model inside your own
  project, but not hand the model file on to others, and the game page contains it. Fine for friends; for a public release
  replace it or ask the author.
- **Crosswalk picture.** Its file name looks like a stock-vector download (it came as an .eps). If it came from a
  stock site, that site's licence usually asks for a credit line to the author; add it in the last row above.
- Brand names (Mazda, Ford, McLaren) appear only as the names of the real cars the models depict; the garage uses its
  own Indian-style names.
