## Things to settle before sharing the game publicly

- **McLaren F1 (CC BY-NC 4.0)** may be used only for non-commercial purposes. A free hobby game is fine; ads, a
  paid version or sponsorship are not. Remove `assets/mclaren.glb` and its entry in `src/assets.js` / `src/carspecs.js`
  if that could change.
- **Ford F-150 (Sketchfab "Standard" licence)** is not a Creative Commons licence: it lets you use a downloaded model
  inside your own project, but not hand the model files on to others, and the game page contains the model. It is
  safest for private use with friends. For a public release, replace it or ask the author.
- **Crosswalk picture.** Its file name looks like a stock-vector download (it came as an .eps). If it came from a
  stock site, that site's licence usually asks for a credit line to the author; add it in the last row above.
- Brand names (Mazda, Ford, McLaren) appear only as the names of the real cars the models depict; the garage uses its
  own Indian-style names.
